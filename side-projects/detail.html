Kinetic Typography Engine.

Category

Experimental Web

Tech

Three.js / GLSL

Status

v1.2 Deployed

01 / Concept 02 / Technical

01 / Concept

An exploration into the intersection of traditional typography and dynamic motion. This engine was built to test how variable fonts can respond to environmental audio data in real-time, creating a physical sense of weight within digital text.

02 / Technical

Built using a custom WebGL pipeline. Each character is rendered as a signed distance field (SDF), allowing for infinitely sharp scaling and complex GPU-based distortions without sacrificing performance.
